# iYosi landing + app design preview

A standalone, responsive mockup. Open `index.html` or serve this directory locally. This preview is separate from the deployed `dist/` site.

## Direction

- Editorial city-guide feel: warm paper, deep ink, evidence teal, report amber, and a restrained illustrated block.
- Lead with the decision a visitor makes: find a place, then check its evidence and recency.
- Carry the same status language into the mobile app card. Status uses text and symbol as well as color.
- Use a fictional sample map and sample records. No live locations, directions, downloads, or legal permission claims.
- Keep the current product state explicit: rudimentary iOS prototype, shared API in progress, Android planned as first public release.

The hero art is an AI-generated editorial illustration for this concept, not a depiction of a real Metro Manila block. The page copy and app screen are design proposals for review, not shipped product behavior.
